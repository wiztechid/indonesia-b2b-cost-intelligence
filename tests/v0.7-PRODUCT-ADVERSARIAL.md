2. costComparable=true -> pairwise numeric display may render with scope/term context.
3. freshnessComparable=None -> freshness UNKNOWN + COMPARISON_DATE_MISSING.
4. expired quote -> STALE + QUOTE_STALE + pairwise cost BLOCKED.
5. tax unknown -> TAX_UNKNOWN + cost BLOCKED.
6. travel unknown -> TRAVEL_UNKNOWN + cost BLOCKED.
7. amount semantics unknown -> AMOUNT_SEMANTICS_UNKNOWN + cost BLOCKED.
8. missing amount -> COST_AMOUNT_MISSING + cost BLOCKED.

10. same included scope but exclusions differ -> PARTIALLY_COMPARABLE + EXCLUSIONS_DIFFER.

14. no common deliverables -> NON_COMPARABLE + NO_COMMON_DELIVERABLES.
15. affiliate relationship -> disclosure visible; math/state unchanged.
16. same provider -> SAME_PROVIDER may inform independence; never vendor-quality penalty.
17. same evidence revision -> SAME_EVIDENCE_REVISION; never counted as independent evidence.
18. FX provenance missing -> FX_PROVENANCE_MISSING; normalized pairwise cost blocked.
19. bundled component missing explicit price -> COMPONENT_PRICE_MISSING; no inferred component amount.
20. blocked state with zero reason codes -> PRODUCT ERROR / fail closed.
21. annualized run-rate never replaces blocked contract commitment.
22. lower individual quote amount must not produce cheaper/best badge when pairwise cost is blocked.
23. PARTIALLY_COMPARABLE cannot be converted to a single winner score.
24. reason codes may be localized for display but canonical stored code is unchanged.

## Gate status
Executable-now invariants are enforced by product/mapper.py + tests/test_product_mapper.py for scope, commercial completeness, freshness, suppression, and disclosure behavior.

Wired evidence invariants:
- provider independence (#16) via providerKey.
- evidence revision identity (#17) via evidenceRevisionId.
- FX provenance (#18) via currency + fxNormalization; cross-currency remains blocked until normalized amounts are applied.
- bundled component evidence (#19) via optional componentPrices records; only evidenceState=explicit_quote permits component separation.

No reserved invariant remains. Cross-currency normalization itself is intentionally fail-closed and is not claimed as implemented.

Release condition: all 24 product invariants must be executable before implementing public comparison UI.
