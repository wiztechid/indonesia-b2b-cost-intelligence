# Buyer Intelligence v0.4 Adversarial Tests

1. Vendor A IDR 3m consultation vs Vendor B IDR 50m implementation -> NON_COMPARABLE.
2. Quote says IDR 100m but tax unspecified -> retain amount; tax=UNKNOWN; never assume included.
3. Monthly DPO quote with 12-month minimum -> annualization allowed only with term disclosed.
4. DPIA quote bundles pentest -> separate only if component prices exist; otherwise mark bundled.
5. Cheapest quote has half the deliverables -> do not rank cheapest as best.
6. Affiliate vendor submits quote -> commercial relationship cannot change evidence score.
7. Missing exclusions -> lower coverage; do not infer none.
8. International DPO benchmark -> methodology/context only; cannot seed Indonesian market range.
9. Three quotes from same vendor brands/pages -> one provider independence key.
10. High evidence-coverage score -> must not be displayed as compliance/vendor-quality score.
11. Empty organization/scope objects -> schema validation FAIL.
12. DPO training/course price -> NON_COMPARABLE with DPO-as-a-Service.
13. Unknown material scope value -> preserve null/UNKNOWN; never coerce to zero/false.
14. Extra unrecognized payload fields -> schema validation FAIL.

Release condition: all fourteen invariants must be preserved by any future implementation.
