# Quote Comparison Engine v0.5 Adversarial Gate

1. Same DPO scope A/B; C is DPO training -> C NON_COMPARABLE.
2. Monthly 12-month minimum vs annual -> compare only after disclosed annualization.
3. Tax unknown -> UNKNOWN, never zero.
4. Incident response included vs excluded -> partial, no cheapest winner.
5. Revised quote from same provider -> preserve revision lineage; not independent.
6. Foreign currency -> normalization requires rate source + rate date.
7. Missing amount -> scope comparison allowed; cost comparison blocked.
8. High evidence coverage + high price -> no negative vendor inference.
9. Low evidence coverage + low price -> no positive vendor inference.
10. Sponsor/affiliate/lead partner -> no evidence/ranking boost.
11. Bundled pentest -> no invented component price.
12. A~B comparable, B~C partial, A~C non-comparable -> preserve pairwise states.
13. Empty exclusions array is not proof of no exclusions unless explicitly attested.
14. Expired quote -> historical only; stale for current procurement.
15. FX-normalized output retains original amount/currency.
16. Missing commercialRelationship -> schema FAIL.
17. FX conversion without provenance -> normalized cost BLOCKED.
18. Unknown quantity limit -> cannot be coerced to unlimited.
19. One provider submits multiple brands/pages -> independence key remains provider-level.
20. Pairwise comparison result cannot be transformed into universal vendor score.

Release condition: all 20 invariants must hold before UI publication.
